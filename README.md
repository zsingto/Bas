# 🏀 Auto Shot Clock

เว็บแอปช็อตคล็อคบาสเกตบอลที่ **หยุดนาฬิกาอัตโนมัติเมื่อได้ยินเสียงนกหวีดกรรมการ** ผ่านไมโครโฟน
ไฟล์ HTML/JavaScript ล้วน ไม่ต้องติดตั้งอะไร ใช้ได้บนคอมพิวเตอร์ แท็บเล็ต มือถือ หรือต่อจอใหญ่ข้างสนาม

## ความสามารถ

- **ช็อตคล็อค 24 / 14 วินาที** (ปรับได้ — มี preset FIBA, NBA, FIBA 3x3)
- **เกมคล็อค + ควอเตอร์ / ต่อเวลา (OT)** — ช็อตคล็อคเดิน/หยุดพร้อมเกมคล็อคเสมอ
- **ฟังเสียงนกหวีดอัตโนมัติ** — ได้ยินนกหวีดปุ๊บ นาฬิกาหยุดทันที (ช่วยลดความล่าช้าจากคนกด)
- **ยกเลิกการหยุด (U)** — ถ้าระบบหยุดผิดจังหวะ กดแล้วนาฬิกาเดินต่อเหมือนไม่เคยหยุด (หักเวลาให้ถูกต้อง)
- **บัซเซอร์** เมื่อช็อตคล็อคหรือเกมคล็อคหมด
- ต่ำกว่า 5 วินาทีแสดงทศนิยม, ปิดช็อตคล็อค (––) เมื่อเวลาเกมเหลือน้อยกว่า
- รีเซ็ต 14 แบบกติกา FIBA (`Shift+T` = รีเซ็ตเป็น 14 เฉพาะเมื่อเหลือน้อยกว่า 14)
- บันทึกเวลาที่เป่านกหวีดแต่ละครั้ง, กันหน้าจอดับ, โหมดเต็มจอ, จำค่าตั้งค่าไว้ในเบราว์เซอร์

## วิธีใช้

ไมโครโฟนในเบราว์เซอร์ต้องเปิดผ่าน `https://` หรือ `localhost` จึงแนะนำให้รันเซิร์ฟเวอร์ในเครื่อง:

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

หรือเปิด `index.html` ตรง ๆ ก็ได้ (Chrome อนุญาตไมค์บน `file://` แต่บางเบราว์เซอร์ไม่อนุญาต)
ถ้าจะใช้บนมือถือ ให้ host ผ่าน https เช่น GitHub Pages

### คีย์ลัด

| ปุ่ม | ทำอะไร |
|---|---|
| `Space` | เริ่ม / หยุด |
| `R` | รีเซ็ต 24 |
| `T` | รีเซ็ต 14 |
| `Shift`+`T` | รีเซ็ต 14 ถ้าเหลือน้อยกว่า 14 |
| `↑` / `↓` | ช็อตคล็อค ±1 วินาที |
| `Shift`+`↑` / `↓` | เกมคล็อค ±1 วินาที |
| `U` | ยกเลิกการหยุดล่าสุด |
| `W` | เปิด/ปิดไมค์ฟังนกหวีด |
| `N` | ควอเตอร์ถัดไป |
| `B` | บัซเซอร์ |
| `F` | เต็มจอ |

### ปรับจูนการตรวจจับนกหวีด

เปิด ⚙︎ ตั้งค่า แล้วเปิดไมค์ จะเห็นแถบวัดแบบสด ลองเป่านกหวีดในสนามจริง:

- แถบต้อง **เกินขีดสีส้ม** ตอนเป่า และ **ต่ำกว่าขีด** ตอนมีแค่เสียงคนดู/เสียงลูกบอล
- เสียงรบกวนทำให้หยุดเอง → ลด "ความไว" หรือเพิ่ม "ต้องดังต่อเนื่อง"
- เป่าแล้วไม่หยุด → เพิ่ม "ความไว" หรือดูว่าความถี่ยอด (Hz) อยู่ในย่านที่ตั้งไว้ไหม
- วางไมค์/อุปกรณ์ใกล้โต๊ะเจ้าหน้าที่ และหันออกจากลำโพงในสนาม

## หลักการตรวจจับ

นกหวีดกรรมการเป็นเสียงโทนเดียวความถี่ประมาณ 2–4.5 kHz ที่ดังโดดเด่น ส่วนเสียงคนดูเป็นเสียงกว้างทุกความถี่
โปรแกรมทำ FFT จากไมค์ทุก ~16 ms หายอดในย่านนกหวีด แล้ววัดว่าสูงกว่าค่ามัธยฐานของทั้งสเปกตรัมกี่ dB
ถ้าโดดเด่นเกินเกณฑ์ **ต่อเนื่อง ≥ 140 ms** จึงถือว่าเป็นนกหวีด (ตัดเสียงสั้น ๆ เช่นรองเท้าเสียดพื้น)
นกหวีดยาวหนึ่งครั้งนับเป็นหนึ่งครั้ง และระบบจะไม่ฟังขณะบัซเซอร์ของตัวเองดัง

> ⚠️ ระบบช่วยลดภาระเจ้าหน้าที่ แต่ควรมีคนดูแลอยู่เสมอ (เริ่มนาฬิกา, รีเซ็ต, และกด `U` ถ้าหยุดผิด)

## โครงสร้าง

```
index.html      หน้าจอและสไตล์
js/clock.js     ตรรกะนาฬิกาเกม/ช็อตคล็อค (ไม่ผูกกับ UI)
js/whistle.js   ตัวตรวจจับนกหวีดจากสเปกตรัม
js/app.js       เชื่อม UI, เสียงบัซเซอร์, ไมโครโฟน, คีย์ลัด
test/           ชุดทดสอบ (node --test)
```

## ทดสอบ

```bash
npm test
```

ชุดทดสอบตัวตรวจจับใช้เสียงสังเคราะห์ (นกหวีด + เสียงคนดู, white noise, เสียงสั้น, โทนนอกย่าน) ผ่าน FFT แบบเดียวกับเบราว์เซอร์
